# Cursor Prompting Protocol

Always follow this sequence.

For new features:
1. Read relevant docs and files.
2. Ask clarifying questions if requirements are unclear.
3. Propose a concise plan.
4. Wait for approval if the task affects more than three files.
5. Implement in small slices.
6. Explain changed files.
7. Tell me how to test.

For debugging:
1. Do not rewrite the whole feature.
2. Inspect the relevant files.
3. State the likely cause.
4. Make the smallest fix.
5. Explain how to verify.

For styling:
1. Preserve the Puff Note design direction.
2. Do not create generic SaaS UI.
3. Avoid ecommerce language.
4. Keep the page airy and editorial.
5. Mood bubbles should remain tactile and soft.

For explanation:
Assume I can read code but may be rusty.
Explain components simply:
What it does
Where it is used
What state it receives
What state it changes
